Denon MC2000 コントロールマップ

写真上の番号で各ノブ・ボタンを呼び分けるための対応表です。番号は左デッキ L・右デッキ R が鏡像で同じ番号、中央の共通部分が C。「R6のSHIFT時を○○にして」のように指定してください。内容は gThomas99 版（v0.1.1-pre-beta）の Denon-MC2000.midi.xml / Denon-MC2000-scripts.js を読んだ結果です。

枠にカーソルを乗せると下の表の行が光り、クリックするとその行へ移動します。表の行に乗せても写真側が光ります。

L1–L7 / R1–R7
FXセクション。1–3 がFXノブ、4 が BEATS ノブ（押し込み可）、5–7 がFXボタン。
L8–L17 / R8–R17
LOOP 列（IN, OUT, −, AUTO, +）、HOT CUE 1–4、SAMPLE MODE。
L18–L26 / R18–R26
デッキ下部。KEY LOCK、ピッチフェーダー、ジョグ、VINYL MODE、SYNC、CUE、PLAY、PITCH BEND −/+。
L27–L33 / R27–R33
ミキサーのチャンネル列。LEVEL、HI、MID、LOW、フェーダー、モニターCUE、LOAD A/B。
C1–C10
中央と両端の共通部。SEL、BACK、FWD、BROWSE1/2、SHIFT、クロスフェーダー、MONITOR PAN、PHONES、MASTER。

起動時と設定スイッチ

  • 起動すると全LEDが1秒点灯してから通常表示に戻ります。KEY LOCK の点滅回数が現在のピッチ幅です。
  • 音量・EQ・ピッチを安全な値に戻し、Deck1 のモニターCUEをONにします。ノブを少し動かすと実機の位置が反映されます。
  • スクリプト先頭の MC2000Config で挙動を切り替えられます。 pregainAsFilter（LEVEL をフィルターにする、現在 ON）、 useAltPitchBend（SHIFT+BEND を32拍ジャンプにする、現在 ON）、 useAltPlayShift（SHIFT+PLAY を逆再生ロールにする、現在 OFF）、 setVolumeToSafeDefault（起動時の音量リセット、現在 ON）。
  • FX をどのデッキに通すかは Mixxx の画面で選びます。初期状態は FX1 が Deck1、FX2 が Deck2。

VINYL / SAMPLE MODE の仕組み

  • どちらもモード切替は本体側で行われます。ON/OFF で本体が送ってくる番号そのものが変わり、LED も本体が自分で点け消しします。
  • VINYL ON: ジョグ天面タッチ 51・回転 51。OFF: タッチ 56（未割当なのでスクラッチしない）・回転 52（ピッチベンド）。
  • SAMPLE OFF: パッドは 17 18 19 20（ホットキュー）。ON: 左 21–24・右 31–34（サンプラー）。
  • そのため Mixxx の画面にはモード表示がありません。動作で見分けます。

MIDI仕様の要点（公式マニュアル p.14–16）

種類形式
ボタン9n 番号 40（押下） / 8n 番号 00（離す）
ノブ・フェーダーBn 番号 00–7F
FXノブ・BEATS・SELBn 番号 01 / 7F（相対）
ジョグ回転Bn 51 41–7F 正転 / 3F–01 逆転
ピッチフェーダーEn LSB MSB（14bit）
LED 点灯 / 消灯 / 点滅Bn 4A / 4B / 4C LED番号
モニターCUE LEDBn 50 / 51 LED番号
全フェーダー値の要求B0 4A 39

n = 0 が左デッキ、1 が右デッキ。FXボタン・FXノブ・BEATS・SHIFT・LOAD・ブラウズ系は左右どちらも n = 0 で届きます。
